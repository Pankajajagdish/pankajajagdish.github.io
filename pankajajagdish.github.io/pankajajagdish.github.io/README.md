# Pankaja Kulkarni | Azure DevOps Engineer Portfolio

Personal portfolio site: production case studies (problem, before, after, impact) and end-to-end Azure DevOps lab projects.

Live site: https://pankajajagdish.github.io

## Files

- `index.html`: the whole site (HTML and CSS in one file, no build step)
- `.nojekyll`: tells GitHub Pages to serve the file as-is

## Host it on GitHub Pages

1. Create a public repository named exactly `pankajajagdish.github.io`.
2. Upload these files to the root of the repo and commit to `main`.
3. Go to Settings, then Pages. Under "Build and deployment", choose "Deploy from a branch", select `main` and `/ (root)`, then Save.
4. Wait 1 to 3 minutes. The site goes live at https://pankajajagdish.github.io.

## Edit later

Open `index.html` on GitHub, click the pencil icon, change the text, and commit. The site updates in a minute or two.
